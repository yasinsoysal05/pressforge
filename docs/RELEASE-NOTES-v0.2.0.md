# PressForge v0.2.0 — Alpha Source Preview

First public open-source source-code milestone for **PressForge**, an independent WordPress development studio targeting Intel macOS Ventura.

## Included

- Tauri 2 / Rust desktop backend and React / TypeScript UI.
- Experimental WordPress site management, WP-CLI bootstrap, local PHP processes, and logs.
- Bundled-runtime preparation scripts for PHP, MariaDB, and WP-CLI.
- Experimental Intel macOS DMG GitHub Actions workflow.
- Technical documentation, security notes, MIT license, contributor information, and changelog.

## Important limitations

**This is not a tested DMG application.** Native macOS builds and end-to-end WordPress setup on Intel Ventura have not yet been verified. The experimental bundled MariaDB/PHP binaries and signing/notarization require additional work and legal review of third-party distributions.

The attached ZIP is a **source archive**, not a precompiled installer. Please do not use this release for production websites or client data.
